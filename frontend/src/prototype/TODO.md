# ReturnShield Prototype

AI-trust visual system and interaction requirements:
- Futuristic light UI with violet and teal accents, glass surfaces, responsive 390px support, and WCAG AA contrast.
- Animated catalog, product cards, 3D tilt, shared transitions, scroll reveals, and sticky navigation.
- Fit-check idle, input, loading, result, low-score, low-data, and error states.
- Animated gauge, staggered reasons, theme bars, alternatives carousel, swap morph, and confetti.
- Reusable GlassCard, TiltCard, AnimatedGauge, ScanLoader, and StaggerList components.
- Respect prefers-reduced-motion and animate primarily transform and opacity.
- Prototype data only; do not represent it as a production API integration.
